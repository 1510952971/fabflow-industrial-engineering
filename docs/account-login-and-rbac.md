# FabFlow 账号登录与权限管理

FabFlow 的公开页面允许匿名只读浏览。新增、修改、删除、审批、主数据维护和账号管理必须登录，并由服务端按项目范围校验 RBAC 权限。

## 管理入口

1. 使用管理员账号登录。
2. 点击左下角头像右侧的 `···`。
3. 点击“账号与权限管理”。系统会直接打开“数据底座与协同 → 权限与审批”，无需再手工切换页签。

## 管理员可执行的操作

- 开通账号：填写姓名、邮箱、初始密码、角色和授权范围后创建。
- 启用/停用：停用会立即撤销该账号的全部登录会话；重新启用后方可登录。
- 重置密码：管理员设置新密码，原有会话立即失效。
- 删除账号：移除密码凭据和全部角色，账号不可再次登录；为保证审计链完整，数据库只保留不可用的删除标记和历史审计记录。
- 权限配置：授予或移除平台管理员、项目经理、系统负责人、设备材料工程师、审核人、只读用户角色。
- 授权范围：`platform_admin` 固定为全局范围；其他角色可以限定当前项目或全部项目。

系统禁止管理员删除或停用自己，也禁止删除、停用最后一个有效平台管理员，避免系统失去管理入口。

## 用户修改自己的密码

1. 登录后点击左下角头像右侧的 `···`。
2. 点击“修改我的密码”。
3. 输入当前密码、新密码并再次确认。
4. 修改成功后，系统撤销该账号所有设备上的登录会话；使用新密码重新登录。

密码至少 10 位，并同时包含字母和数字。密码使用 PBKDF2-SHA-256 和独立随机盐存储，D1 不保存明文密码。

## 首次本地运行

```powershell
npm run db:migrate:local
npm run dev
```

打开页面后点击“登录账号”。当系统还没有密码账号时，会显示“初始化系统管理员”；本机 `localhost` 初始化不要求一次性口令。

## 生产环境首次初始化

先设置仅使用一次的初始化口令：

```powershell
npx wrangler secret put AUTH_BOOTSTRAP_TOKEN
npm run db:migrate:remote
```

发布后在登录窗口输入相同的一次性口令，创建首个管理员。完成后删除 Secret：

```powershell
npx wrangler secret delete AUTH_BOOTSTRAP_TOKEN
```

## 安全与审计规则

- 浏览器使用 HttpOnly、SameSite=Lax 会话 Cookie；D1 只保存会话令牌的 SHA-256 哈希。
- 连续 5 次密码错误会锁定账号 15 分钟。
- 登录、退出、开通、停用、启用、删除、重置密码、自助改密和角色变更均写入审计日志。
- 删除采用保留审计标记的软删除，防止历史审批、操作人与签字链断裂。
- 权限判断在服务端执行，隐藏前端按钮不作为安全边界。
