# FabFlow 账号登录与管理员初始化

FabFlow 公开页面继续允许匿名只读浏览；工程数据新增、修改、删除、审批和账号管理必须登录，并由服务端按项目范围校验 RBAC。

## 首次本机运行

1. 执行 `npm run db:migrate:local` 创建账号凭据和会话表。
2. 执行 `npm run dev`，打开页面后点击右上角“账号登录”。
3. 系统没有密码账号时会显示“初始化系统管理员”。本机 `localhost` 初始化不要求一次性口令。
4. 输入管理员姓名、邮箱和至少 10 位且同时包含字母、数字的密码。

## 生产环境首次初始化

先设置只使用一次的初始化口令：

```powershell
npx wrangler secret put AUTH_BOOTSTRAP_TOKEN
npm run db:migrate:remote
```

发布后打开登录窗口，输入相同的一次性初始化口令创建首个管理员。完成后建议删除此 Secret，后续账号全部由管理员在“数据底座与协同 → 权限与审批”中创建：

```powershell
npx wrangler secret delete AUTH_BOOTSTRAP_TOKEN
```

## 安全规则

- 密码使用 PBKDF2-SHA-256 和独立随机盐哈希，D1 不保存明文密码。
- 浏览器只保存 HttpOnly、SameSite=Lax 会话 Cookie；D1 只保存会话令牌的 SHA-256 哈希。
- 连续 5 次密码错误会锁定账号 15 分钟。
- 管理员重置密码或停用账号会立即撤销该账号全部会话。
- 系统阻止停用最后一个有效管理员，也阻止管理员移除自己的管理员角色。
- `platform_admin` 为全局管理员；其他角色可按当前项目或全部项目授权。
- 所有登录、退出、建号、停用、重置密码及角色变更写入审计日志。

## 管理员能力

- 创建密码账号并同时授予初始角色。
- 启用或停用账号。
- 重置密码并强制旧会话失效。
- 授予或移除系统管理员、项目经理、系统负责人、设备/材料工程师、审核人、只读用户角色。
- 选择授权范围为当前项目或全部项目。
