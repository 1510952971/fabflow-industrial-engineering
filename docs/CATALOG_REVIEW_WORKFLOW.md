# 全局设备材料型录审核流程

## 适用范围

设备材料型录是公司级全局主数据，不按项目复制。项目技术规格书只创建项目选型要求，并引用已批准的全局产品、型号和适用性记录。

公开访客可以浏览已开放数据，但不能录入、送审或批准。产品维护需要全局写权限；送审和批准仅允许平台管理员执行，权限由服务端校验。

## 状态流转

1. **待复核草稿（draft）**：录入或导入后的初始状态。可继续补充通用参数、分类专用参数、适用系统、来源文件、页码、图片和厂家链接。
2. **待审核（pending_review）**：管理员在“型录审核工作台”批量送审。缺少适用系统、来源证据、身份字段或分类必填规格时禁止送审。
3. **已批准（approved）**：只能由待审核状态批准。本地来源文件必须填写来源页码或条款；厂家正式 URL 可作为在线来源证据。
4. **有条件（conditional）**：已识别但仍有工程限制或适用边界的产品，需要在说明、适用性或限制字段中补充条件。
5. **退回补资料（rejected）**：资料错误、型号不唯一或证据不足。修订后保存为草稿，再次送审。

已批准或待审核产品进入编辑器时会自动回到草稿，避免参数修改后沿用旧批准结论。

## 管理员操作

1. 登录平台管理员账号，进入“厂务大型设备库 / 全局设备材料型录库”。
2. 使用系统、分类、审核状态和资料完整度筛选产品。
3. 选择单个产品，或使用“选择当前结果”。每批最多 100 条。
4. 对“可送审”草稿执行“批量送审”。失败产品会保留原状态并显示具体缺项。
5. 将审核状态筛选为“待审核”，核对型号、参数、适用系统、来源文件和来源页码。
6. 勾选合格产品，执行“批量批准”。草稿不能跳过送审直接批准。
7. 在审计日志中查询 `catalog_product.pending_review` 和 `catalog_product.approved`，确认操作者、时间和前后状态。

## 数据质量规则

- 产品分类、制造商、品牌、产品编码、产品名称、完整型号为必填。
- 至少关联一个统一 FAB 系统代码。
- 分类模板中的必填动态规格必须通过类型、范围和选项校验。
- 至少提供本地来源文件或厂家正式 URL。
- 使用本地文件批准时必须填写来源页码或条款。
- 文件名识别和 OCR 结果只生成草稿或候选，不自动成为批准产品。
- 通用主数据新增、批量导入和修改接口不能直接写入待审核或已批准状态。
- 每次状态变更写入审计日志，产品内容修改进入版本记录。

## 项目选型关系

项目上传技术规格书后，系统提取介质、压力、温度、尺寸、接口、材料、品牌、标准、认证和分类专用参数，在全局型录中匹配。匹配结果必须经过工程规则校验后，才可作为项目选型结果或进入 BOM；项目不会复制和篡改全局产品主档。
